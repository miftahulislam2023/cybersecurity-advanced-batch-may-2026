## OSI - The Open Systems Interconnection (OSI)

### OSI Layers
- Acronym -> (An acronym used to help remember the model from bottom to top is "Please Do Not Throw Sausage Pizza Away." From top down the "All People Seem To Need Data Processing" acronym can be utilized.)
1. Application Layer
2. Presentation Layer
3. Session Layer
4. Transport Layer
5. Network Layer
6. Datalink Layer
7. Physical Layer
- Three things are related to each layer
  1. Services -> what the layer does
  2. Protocol -> a set of rules of doing something
  3. Interface -> tells the processes above it how to access it

## Interface
- UI -> User Interface
- GUI -> Graphical User Interface
- An interface is a shared boundary, connection, or point of communication where two separate systems, devices, or people meet and interact

## Protocol
- A set of well defined rules of doing something -> A protocol is a set of rules or procedures that govern how an activity, process, or communication should be done

## Service
- A set of capabilities or functions that a specific layer (the service provider) offers to the layer directly above it (the service user) through a vertical interface

## The Upper Layer
- **Application specific functions** like data formatting, encryption, and connection management
1. Application Layer
2. Presentation Layer
3. Session Layer

## Lower Layer
- Primitive **network-specific functions** like routing, addressing, and flow controls
1. Transport Layer
2. Network Layer
3. Datalink Layer
4. Physical Layer
